## Topics to be Documented

- **Prerequisites:** Python 3.10+, Node.js 18+, package managers.
- **Backend Setup:** Virtual environment setup, installing dependencies via `requirements.txt`, environment configuration via `.env`, and running `uvicorn app.main:app --reload`.
- **Frontend Setup:** Setting up Next.js + TypeScript within `frontend/` and running the dev server via `npm run dev`.
- **Testing & Quality Checks:** Running test suites (`pytest`), formatting (`ruff` or `black`), and linting.
- **Git & Branching Workflow:** Conventions for feature branches, commit messages, and pull requests.
