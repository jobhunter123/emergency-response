# Development Guide

This guide describes how to set up, develop, and test the Emergency Response Platform backend.

---

## 1. Prerequisites

- **Python**: 3.10+ (Python 3.11 recommended)
- **Git**: For version control
- **Node.js**: 18+ (for frontend development in future phases)

---

## 2. Backend Setup

All backend code resides in the `backend/` directory.

### Step 2.1: Navigate to the backend directory

```bash
cd backend
```

### Step 2.2: Create a virtual environment

Create an isolated Python virtual environment:

**Windows (PowerShell):**
```powershell
python -m venv .venv
```

**macOS / Linux:**
```bash
python3 -m venv .venv
```

### Step 2.3: Activate the virtual environment

**Windows (PowerShell):**
```powershell
.venv\Scripts\Activate.ps1
```
*(If script execution is restricted, run: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process` or use `.venv\Scripts\activate.bat` in CMD)*

**macOS / Linux:**
```bash
source .venv/bin/activate
```

### Step 2.4: Install dependencies

Install all required packages from `requirements.txt`:

```bash
pip install -r requirements.txt
```

### Step 2.5: Configure Environment Variables

Copy the example environment configuration:

**Windows (PowerShell):**
```powershell
Copy-Item .env.example .env
```

**macOS / Linux:**
```bash
cp .env.example .env
```

Review `.env` and configure settings as needed for local development:
- `APP_NAME`: Application display name
- `ENVIRONMENT`: Runtime environment (`development`, `staging`, `production`)
- `DEBUG`: Enable or disable debug mode (`True` / `False`)
- `DATABASE_URL`: SQLAlchemy connection string (defaults to SQLite: `sqlite:///./emergency_response.db`)
- `SECRET_KEY`: Secret key for cryptographic signing and JWT tokens
- `ACCESS_TOKEN_EXPIRE_MINUTES`: Expiration window for access tokens (in minutes)

---

## 3. Starting the FastAPI Server

Ensure your virtual environment is activated and you are in the `backend/` directory:

```bash
uvicorn app.main:app --reload
```

The server will start at:
- **API Base URL**: `http://127.0.0.1:8000`
- **Health Check**: `http://127.0.0.1:8000/health`
- **API Root**: `http://127.0.0.1:8000/`

---

## 4. API Documentation (Swagger & ReDoc)

Interactive API documentation is automatically generated by FastAPI:

- **Swagger UI**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)
- **OpenAPI Schema**: [http://127.0.0.1:8000/openapi.json](http://127.0.0.1:8000/openapi.json)

---

## 5. Running Tests

Run the test suite from the `backend/` directory:

```bash
pytest
```

To run with verbose output:

```bash
pytest -v
```

To run a specific test file:

```bash
pytest tests/test_health.py -v
```

---

## 6. Project Architecture & Standards

- **Settings**: Centralized in `app.core.config` using Pydantic Settings.
- **Security Utilities**: Reusable password hashing and JWT token handling in `app.core.security`.
- **Database Session**: Dependency-injected sessions via `app.db.session.get_db`.
- **Database Base**: Declarative base in `app.db.base.Base` for future ORM models.
- **No Global DB Sessions**: Route handlers must receive database sessions via `Depends(get_db)`.
- **Type Annotations**: All functions and route handlers should be explicitly typed.

---

## 7. Frontend Setup & Development

All frontend code resides in the `frontend/` directory.

### Step 7.1: Navigate to the frontend directory
```bash
cd frontend
```

### Step 7.2: Configure Environment
```bash
cp .env.example .env
```
Ensure `VITE_API_URL` points to the running backend (default `http://localhost:8000`).

### Step 7.3: Install Dependencies
```bash
npm install
```

### Step 7.4: Start Vite Dev Server
```bash
npm run dev
```
Access the client application at `http://localhost:5173`.

### Step 7.5: Typecheck & Build
```bash
npx tsc --noEmit
npm run build
```
